# 📘 Takaful Commission Calculator  
A simple Python-based calculator designed to help Takaful agents quickly estimate their yearly commission for both **Non Investment-Linked (NIL)** and **Investment-Linked (ILP)** plans.

This tool is built for learning Python, portfolio building, and practical use in daily Takaful work.

---

## 🚀 Features
✔ Supports **2 plan types**:  
- **NIL** (Non Investment-Linked)  
- **ILP** (Investment-Linked)

✔ Accurate commission rate mapping for **Year 1–6**  
✔ Clean, interactive command-line interface  
✔ Beginner-friendly Python code  
✔ Fully open source — feel free to fork, edit, or improve
